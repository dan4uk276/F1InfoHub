F1InfoHub — Formula 1 information web application.

The project is an information portal where users can view data about drivers, teams, race schedules, and championship results. 
The application retrieves information from external sources, processes it, and provides it to users through a convenient web interface.
![img.png](.\images\img.png)
The main focus is on backend development: a database was designed and implemented for storing information, a REST API was developed for handling requests, and integration with external Formula 1 APIs was configured. 
The business logic of the application was implemented, including data processing and validation, and a multi-layered architecture organization.
![img_1.png](.\images\img_1.png)
Functionality includes viewing information about drivers and teams, race calendar, Grand Prix results, championship standings, as well as search and filtering capabilities.
